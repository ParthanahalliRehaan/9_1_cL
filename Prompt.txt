## `llm-stack` — human-gated model orchestration repo (v1: chat + image)

**Goal:** Catalog and orchestrate the best *locally-runnable* models for chat and image generation, constrained to a single **NVIDIA RTX 4050 laptop, 6GB VRAM**, with a human-in-the-loop orchestrating agent.

### Hardware constraint (drives every model choice below)
- 6GB VRAM, laptop-class GPU — no two models resident simultaneously
- Orchestrator loads/unloads models on demand per stage (pool-manager pattern, or delegate to a runtime that already does this, e.g. Ollama's idle-eviction)

### Pipeline architecture
Human-gated state machine, not autonomous chaining:

```
User request
  → Agent runs a stage
  → Agent surfaces result to user
  → User approves → Agent runs next stage
  → User rejects  → [OPEN: retry same input / retry with feedback / manual edit — pick one]
```
